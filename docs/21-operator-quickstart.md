# 21 · 录入助手一页上手

> 已批准或已忽略稿要修改时，先「退回待审」再输入。真实 NGA 登录扫描和大书库客户端显示需要在使用者自己的账号与数据库副本上现场核对。

## 双击哪里

完成 README 中的安装步骤后，双击项目根目录的 `启动录入助手.cmd`。

## 第一次要确认什么

1. 首次启动进入「确认数据库副本」：确认检测到的 main-copy.db，或「选择其他副本」
   （原生对话框）／手动输入本地 .db/.sqlite 绝对路径并校验。
2. 「帖子与扫描」→ 输入帖子 URL（默认预填 30099686）→ 添加帖子。
3. 选择扫描起点（从现在 / 从指定页 / 从指定日期）→ 确认扫描起点 → 初始化扫描进度。
4. 需要访问时点「登录 NGA」，在打开的官方页面完成登录 → 我已完成登录。

## 平时点哪三个按钮

1. 「检查新增投稿」——扫描当前帖子，看到页数/楼层/讨论/投稿/待补全/更新结果。
2. 「待审稿件」——补全字段 → 保存修改 → 批准稿件。
3. 在「人工决定」确认标签、时间、来源、正文格式等并保存 →「生成预览」→ 勾选「我已确认大书库已关闭」→「确认生成候选数据库」。

## 交付在哪

「交付与恢复」页显示最新候选（含累计篇数、路径、SHA）；可创建检查点、恢复、
查看历史交付。用单独「查看副本」交给大书库核对，原候选作为不可变证据。

## 常见问题

- 起点已确认但未初始化 → 点「初始化扫描进度」。
- 部分扫描 → 点「继续下一批」。
- 登录过期/验证码 → 关闭窗口点取消，重新登录；取消不等于登录完成。
- 缺字段稿 → 「信息不全」，补全后保存再批准。
- 关闭浏览器标签页 ≠ 退出；用「设置与帮助」的「退出助手」按钮正常停止。

## 边界

- 日期起点按楼层**原始发表日期**（UTC+08:00）筛选，不含 D 日零点之前；时间无法
  判断的 [收录] 稿会保留并提示人工确认，不会漏掉。
- 旧楼层在历史日期后的编辑不保证被发现；用「补查页范围/按日期补查」覆盖。
- 只写新候选副本，不替换正式大书库；多来源/系列类型仍由人工决定。

## 补查历史（TASK-015 新增按钮）

「帖子与扫描」→「补查历史」：选择「按页范围补查」（填起止页）或「按较早日期补查」
（选日期，从第 1 页逐页筛选），查看代价提示后确认；分批可点「继续补查」，随时
「取消补查」。补查只写自己的 `active_rescan` 游标，不影响日常扫描进度。

## 审核状态操作（TASK-015 补齐）

- **批准稿件**：保存后批准，才能保存人工决定并生成预览。
- **忽略稿件**：必须填写理由（写入审计）。
- **退回待审**：已批准但需继续修改时使用（填写理由）；退回后可再次编辑并重新批准。
- **已写入候选（exported）不可直接修改**：页面会禁用写入并说明；如需修订基于新候选处理。

## 未保存保护

切换稿件、切换页签/帖子、筛选或翻页、关闭页面时，若有未保存修改会先提示；
选「留下」不丢输入，选「放弃」才切换。迟到响应不会覆盖当前正在编辑的稿件。
