# ADR-0001：采用独立录入助手

- 状态：已接受
- 日期：2026-08-24

## 背景

当前只有大书库 3.0.2-Final 的 Electron 发行包，没有完整可维护的源代码工程。目标流程还包含 NGA Watcher、Parser、Inbox、人工审核和安全数据库输出。

## 决策

开发独立的本地录入助手，不修改大书库 Electron 本体。通过专用 `umalib_adapter` 生成兼容候选 DB，并使用现有大书库执行最终打开和人工验收。

## 理由

- 避免依赖压缩后的 ASAR 私有模块。
- 不继承现有发布无事务、无备份的问题。
- Watcher、Inbox 和审核流程可以独立演进。
- 大书库升级或替换时只需更换适配器。
- 正式库保持干净，不加入 Inbox 状态表。

## 后果

- 必须维护明确的大书库兼容契约。
- 写库前需要真实数据库进行语义验证。
- 用户需要用现有大书库打开候选 DB 做最终验收。
- 如果未来取得完整大书库源码，可另行评估增加薄的正式导入入口。
