# ADR-0002：默认输出候选数据库副本

- 状态：已接受
- 日期：2026-08-24

## 决策

Database Writer 默认不原地修改用户选择的正式数据库，而是先生成一致的候选副本，在副本内完成单事务写入、完整性检查和回读验证。

## 原因

- 现有大书库保存链没有跨表事务。
- 应用可能正在持有数据库连接。
- SQLite 目标可能包含 WAL/SHM，简单复制主文件不一定构成一致快照。
- 候选副本可以直接由现有大书库打开验收，也便于回滚和分发。

## 强制规则

- 要求原大书库应用关闭。
- 通过 SQLite Backup API 或等价一致性机制生成副本。
- 写前记录基础库哈希和 Schema 指纹。
- 写后记录候选库哈希、SQL 变更摘要和新增 ID。
- 是否替换正式库始终由用户人工决定。
