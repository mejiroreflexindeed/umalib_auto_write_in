# 项目简报

## 一句话目标

制作一个独立、本地部署、规则驱动的半自动录入工具，把 NGA 指定帖子中的投稿整理为待审核记录，并在人工确认后生成兼容“大书库 3.0.2-Final”的候选数据库副本。

## 用户问题

当前录入人员需要反复浏览 NGA 帖子，从普通讨论中寻找投稿，手工复制标题、作者、来源、标签和正文，再使用大书库编辑器发布。机械工作多，遗漏和格式错误难以追踪。

## 产品原则

- 程序承担扫描、筛选、字段提取、格式转换和变更预览。
- 人负责缺失信息、重复作品、来源冲突和系列归类等业务判断。
- 投稿识别与解析依赖公开保留字段，不依赖 AI 猜测。
- 所有正式写入必须经过人工确认。
- 默认输出新的数据库副本，不原地修改正在使用的正式库。

## V1 用户流程

```text
导入一段 NGA 楼层文本或测试样本
→ 识别 [收录]
→ 提取保留字段与正文
→ 进入 Inbox
→ 人工补充和修正
→ 显示大书库变更预览
→ 生成候选 DB 副本
→ 使用现有大书库打开验收
→ 人工决定是否交付
```

## V1 包含

- 确定性投稿 Parser。
- 独立 Inbox SQLite。
- 待录入、信息不完整、疑似重复、已批准、已导出、忽略状态。
- 本地审核表单。
- 结构化来源和正文预览。
- 大书库 3.0.2-Final 兼容适配器。
- dry-run、备份副本、事务写入和写后验证。

## V1 暂不包含

- 无人值守自动发布。
- AI/LLM 解析。
- 所有历史特殊规则。
- 自动裁决同名标签、来源冲突或多楼层合并。
- 修改大书库 Electron 程序。
- Docker、微服务或云端数据库。
