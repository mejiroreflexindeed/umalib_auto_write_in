# 18 · Demo 用户指南（TASK-013）

## 最快走通一篇（约 3 分钟）

1. 双击项目根目录的 `Start-Demo.cmd`（演示数据模式）；终端会打印
   `http://127.0.0.1:<端口>`，浏览器自动打开。
2. 「收集稿件」面板点「导入 颜色与强调示例」。
3. 切到「审核录入」：点该记录 → ① 核对正文；如需保留 NGA 颜色，先点
   「从原文恢复基本格式（预览）」再点「采用此格式并保存正文」→
   ② 点「批准（approved）」→ ③ 填上传时间/来源；标签/系列若出现多个匹配，按 ID/type
   明确选择（零匹配则选择新建 type），点「保存决定」→
   ④ 勾选「我已确认大书库已关闭」→ 点「生成候选」。
4. 切到「交付与恢复」查看最新候选（标注包含本工作区已录入 N 篇）。

## 两种模式

- `Start-Demo.cmd`：synthetic，内置合成标签库与样例，全程离线可演示；
- `Start-Real-Copy.cmd`：real_copy，只读绑定
  `D:\codex\13\umalib-test-data\main-copy.db`，用于真实副本派生；
  加 `--enable-nga` 才允许真实 NGA 读取（每次读取都需人工确认）。
- 再次双击会恢复该模式上次的工作区；`--new-workspace` 另建新工作区；
  `--workspace <uuid>` 打开指定工作区；切换工作区需退出重启。

## 审核流程

- 状态主标签：待审 / 信息不全 / 疑似重复 / 已批准 / 已写入候选 / 已忽略。
- 缺字段稿件为「信息不全」：补字段 → 保存 → 批准。
- 格式：点「从原文恢复基本格式（预览）」查看建议，人工核对后点「采用此格式并保存正文」；
  纯文本写入若检测到格式损失，勾选确认项后才可提交（不默认确认）。
- 标签重名时按 ID/type 选择；系列类型不自动猜；来源按人工顺序，可先预览规范化。
- 生成按钮只写新候选副本，不替换正式库。

## 常见错误

| 提示 | 处理 |
|---|---|
| workspace_locked | 该工作区已被另一个进程打开；关闭另一个窗口 |
| workspace_head_changed | HEAD 已变化；刷新状态后重新预览 |
| operation_conflict | 同一操作 UUID 换了请求；用新 UUID 或沿用原请求重试 |
| recovery_required | 存在未完成操作；到「交付与恢复」面板处理 |
| watcher_locked | 有 .lock 残留；确认无其他扫描后手动删除 |

## 检查点与恢复

- 「交付与恢复」→「创建检查点」；恢复会新建一个工作区（返回新 UUID），
  重启后用 `--workspace <新 UUID>` 进入；原工作区不变。
- 中断/断电后重新打开：交付与恢复面板会列出未完成操作及可执行动作
  （完成恢复 / 放弃未验证尝试）；放弃会保留孤立候选文件。

## 环境检查

```powershell
.\.venv\Scripts\python.exe -B tools\launch_demo.py --check
```

缺 Python 或 .venv 时启动脚本会明确提示；不联网下载任何东西。
