# 大书库录入助手 · 使用说明（体验版）

> 版本：2026-09-27 体验包（EXE，同源 `tools/exe_entry.py`）。本说明面向第一次使用的同僚。
> 定位：把 NGA 帖子里的投稿整理成“待审稿件”，人工审核后生成**新的大书库候选副本**；
> **只读你的正式大书库，永远不修改它**，也不会自动发布。

## 1. 运行要求

- Windows 10/11。
- 需要 Microsoft Edge（登录 NGA、扫描帖子时使用；不登录也可离线审稿）。
- 无需安装 Python：EXE 已自带运行环境。
- 数据默认保存在 EXE 同目录的 `助手数据\` 文件夹；删掉它等于清空助手状态（不影响你的大书库）。

## 2. 启动

1. 双击 `大书库录入助手.exe`。
2. 会弹出一个黑色控制台窗口（**使用期间不要关**），随后自动打开浏览器页面；
   若浏览器没弹出，把控制台里显示的地址 `http://127.0.0.1:xxxxx` 复制到浏览器打开。
3. 页面顶部显示“本机运行 · 127.0.0.1”即正常。

## 3. 首次使用：确认数据库副本

1. 页面出现“首次使用：确认数据库副本”。
2. 程序会自动检测可用的 `main-copy.db`；如果不是你的库，点“选择其他副本…”选你的 `.db` 文件。
3. 点“确认并使用此副本”。
4. 说明：助手从这一刻起只会**读取**该库，生成的新候选都放在 `助手数据\` 里。

## 4.（可选）登录 NGA 并添加帖子

1. 「帖子与扫描」→ 粘贴帖子地址（形如 `https://bbs.nga.cn/read.php?tid=数字`）→「添加帖子」。
2. 点「登录 NGA」→ 在弹出的官方页面手动登录（验证码由你本人完成）→ 回到助手点「我已完成登录」。
3. 选中帖子 → 选择扫描起点（从现在 / 从指定页 / 从指定日期，按 UTC+08:00）→「确认扫描起点」看预览 →「初始化扫描进度」。
4. 点「检查新增投稿」（可先勾“只检查，不导入”演练一遍）。
5. 结果面板会列出：读取页/楼层、讨论、标记投稿、新进待审、待补全、更新待复查、已见投稿、基线内 [收录]、已见讨论、早于日期、时间待确认；
   点「查看待审稿件」会直接跳到本次帖的列表（旧筛选会自动清掉）。

> 没有 NGA 账号或不想联网也可以：使用「手动导入」把一段带 `[收录] [标题] [作者] [标签]` 的文本贴进来，同样能走完审核与生成候选。

## 5. 审核一篇稿件（日常主流程）

1. 「待审稿件」→ 点一行打开。
2. 核对/补全：标题、作者、译者、系列、标签、来源（每行一个链接）、正文。
3. 点「保存修改」→「批准稿件」。
4. **已批准稿的审核字段会变成只读**；要改就先点「退回待审」，改完保存，再重新批准（输入不会丢）。
5. 在“候选数据库人工决定”区：
   - 录入时间（本地时间）；
   - 备注（会写进大书库 notes）；
   - 正文处理：选“纯文本”，或点「从原始楼层提取基础格式」保留颜色/粗体；
   - 标签选择：同名标签会显示 `复用 ID x（类型 n：中文类型）`，需明确选一个；新建标签必须选类型（其他/角色/系列/长篇、合集/争议、不适）；
   - 勾选“我确认选择纯文本时可能丢失格式”（选纯文本时）。
6. 点「保存人工决定」→「生成并查看预览」→ 核对预览内容（标题/作者/时间/来源/标签）→ 勾选“我已确认大书库已关闭”→「确认生成候选数据库」。
   - 生成前请关闭正在编辑的大书库，避免占用文件。

## 6. 交付与恢复

- 「交付与恢复」列出每次生成的候选：库内篇数、SHA、完整路径。
- 可「复制候选路径」「生成单独查看副本」「打开所在文件夹」。
- 「创建检查点」保存当前进度；「恢复为新的工作区」从检查点派生一个新工作区（原工作区与候选保持不变）。
- 大书库核对时请打开“单独查看副本”，核对标题/作者/标签/来源直达/正文颜色粗体/末尾注释。

## 7. 退出与再次使用

- 「设置与帮助」→「退出助手」：页面与控制台一起正常退出。
- 下次双击同一个 EXE：会自动回到上次的工作区，交付页里能看到之前的候选与检查点。

## 8. 常见问题

| 现象 | 处理 |
|---|---|
| 双击后窗口一闪而过 | 极少见；从命令行运行同一 EXE 可看到错误原因，或把错误信息发给我们 |
| 浏览器没自动打开 | 把控制台地址 `http://127.0.0.1:xxxxx` 复制到浏览器 |
| 提示 `item_locked` | 该稿已批准/已导出；先「退回待审」（已导出的需基于新候选处理） |
| 提示 `maintenance_active` | 正在创建检查点，稍等重试 |
| 登录失败（过期/验证码/网络） | 提示会区分原因；验证码需在官方页面手动完成 |
| 扫描没有新稿 | 结果会说明原因（无 [收录] 投稿 / 已见投稿 / 已见讨论 / 早于所选日期 / 时间待确认） |
| 想彻底重来 | 关闭助手，删除 EXE 同目录 `助手数据\` 后重开（不影响大书库） |

## 9. 安全边界与已知问题（体验版）

- 只读原库、只生成候选；所有写入正式大书库的动作都由你本人完成。
- 体验版已知问题（后续集中修复）：已忽略稿的编辑入口存在与“批准稿”类似的死路（先退回可避开）；EXE 形式的登录/扫描仅在开发者本机冒烟，若你的机器上登录异常，请改用源码包方式（`启动录入助手.cmd`）。
- 旧楼历史编辑：扫描按楼层内容变化判断，历史日期之后的旧楼编辑不保证被发现；需要覆盖时用「按较早日期补查 / 按页范围补查」。
- 本体验包未做数字签名，杀毒软件首次可能提示，请自行确认来源后放行。
