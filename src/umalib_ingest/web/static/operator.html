使用步骤

  1. 帖子与扫描：添加帖子 → 选起点（现在/页码/日期）→ 确认起点 → 初始化扫描进度 →（需要时登录 NGA）→ 检查新增投稿。
  2. 待审稿件：补全字段 → 保存修改 → 批准稿件 → 保存人工决定 → 生成并查看预览 → 勾选确认 → 确认生成候选数据库。
  3. 交付与恢复：查看最新候选、复制路径、生成查看副本、创建检查点、恢复为新工作区、退出助手。
